Portal brand standards
Binding reference for every screen of the 254 Engineering Services operations portal. Version 1.0, September 2026.
1. Color
Navy is structural, gold is attention. Gold never decorates; it appears only in the logo, warnings, pending states, and the active-nav bar.

2. Typography
Archivo for headings and figures, Open Sans for everything else. Numbers always use tabular figures in tables and KPIs.

3. Shape and spacing
Desktop cards and panels: 4px radius, 1px #DDE0E4 border, white on #F4F5F7
Desktop buttons and inputs: 3px radius
Mobile cards: 12px radius; mobile buttons: 8px radius, 44px+ hit targets
Status pills: 12px radius; chips and kbd hints: 2px
Panel padding: 16–22px; table rows: 10–13px vertical
Page gutters: 28px desktop, 16px mobile; section gap: 20px
No drop shadows on cards; shadows only on overlays (menus, modals, toasts)
No accent borders (top or left) on cards — alerts use a full tinted box instead
4. Components
Buttons
Hover: navy darkens to #0E2347, borders darken to navy. One primary button per view region.
Status
{{ st.label }} Dot + text, never a filled colored chip. Green = good, gold = pending or warning, navy = in motion, gray = inert, red = failed (sparingly).
System alert
Restricted mode. Bold lead-in names the condition; the sentence after states what is and is not affected.
Absent data
not recorded $0 A missing figure never looks like zero. Dashed italic chip for absent; plain numeral for a true zero. Absent values are excluded from totals, and the exclusion is stated in a footnote.
5. Voice
Write
Action required
Sorted by priority

Showing 1–14 of 14
Never
Needs you!
Ranked by cost of ignoring it
Copy that explains the design's own philosophy
Exclamation marks, emoji, or reassurance
Second-person cleverness ("we've got you")
Sentence case everywhere, including buttons and column headers. Terse and factual; state the condition, then the consequence. Middle dots (·) separate metadata, em dashes introduce a cause. Timestamps are explicit ("Sep 3, 11:42 AM"), currency has no decimals under $10,000, and every table states its own count.
6. Layout patterns
Desktop: 230px navy sidebar (icon + label, gold active bar), 58px white header (title, data-freshness note, search, bell, help, user menu), content max-width 1100–1240px, version footer on every screen.
Tables: uppercase 11px column headers, sortable with ▾ caret, row hover #F8F9FB, pagination footer, Filter/Export/column-config toolbar.
Records: breadcrumb, header band with ref + status pill + actions + labeled field grid, History timeline (dot rail, actor + timestamp per event).
Mobile (390px): navy status bar and header, one-handed reach, cards 12px radius, bottom tab bar, home indicator, sync-status line.
Documents: letters render on a white 760px sheet with letterhead, 2px navy rule, seal + signature block, small-print record note.
